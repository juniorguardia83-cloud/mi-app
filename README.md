# Mi App 🐾

Primera base nativa de Android para un juego de cuidado de mascotas virtuales.

## Primera pantalla
- Una mascota inicial llamada Coco.
- Indicadores de comida, diversión y limpieza.
- Acciones para alimentar, jugar y bañar.
- Misión diaria variable y recompensa de monedas.
- Racha diaria de cuidado.
- Navegación inferior preparada para las siguientes pantallas.

## Estado técnico
Esta primera versión guarda el progreso localmente con `SharedPreferences`. Supabase todavía no está conectado ni verificado en este repositorio. No se incluyen contraseñas ni claves secretas.

## Compilar APK
El flujo de GitHub Actions compila el APK de depuración y lo publica como artefacto en la pestaña **Actions**.
